ArtCraft ruler scrollbar isolated demo

Open index.html locally in Firefox or Chromium. Scroll the blank page, hover over the right edge, or click/drag on the ruler.

Based on actual saved getartcraft.com markup and CSS and the behaviour identified in the provided production JS bundle:
  29wilaqtb26u5.js - React ruler component and motion/scroll handling
  42sbiz42garyr.css - palette and animated percentage digit CSS

The demo is a dependency-free adaptation, not verbatim React source.
